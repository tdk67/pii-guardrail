Protecting Codebases from Accidental PII Leaks
Latch is an on-device git commit guardrail powered by a fine-tuned Julia-1 Small Language Model. It runs entirely offline with realistic 1-2s chunk inference, zero false-alarm regex noise, and strict privacy.
🔒

Git Hook Interception

Installs transparently into .git/hooks/pre-commit. Intercepts diff additions before commits ever reach disk or remotes.

⚡

Warm Daemon Architecture

Background daemon on 127.0.0.1:5138 keeps Julia-1 in RAM, responding to pre-commit health probes in <50ms.

🎯

Binary Dissection

O(log N) divide-and-conquer bisection isolates the exact offending line numbers and code snippets from large staged batches.

📊

Full Observability

Native Prometheus metrics and Grafana dashboards for auditability and compliance without leaking data to cloud APIs.
